# 📊 Flipkart Price & Discount Analysis Dashboard

## 🚀 Project Overview

This project analyzes Flipkart product data to uncover insights related to product pricing, discounts, brand performance, and price segmentation. The analysis was performed using Python, SQL, and Power BI, followed by the development of an interactive dashboard for business insights.

---

## 🎯 Objectives

* Analyze product pricing and discount patterns
* Identify brands with the highest product listings
* Compare average prices across price segments
* Explore product distribution by category and price range
* Build an interactive business intelligence dashboard

---

## 🛠️ Tools & Technologies

* **Python (Pandas, NumPy)**
* **Jupyter Notebook**
* **SQL (SQLite/MySQL)**
* **Power BI**
* **Power Query**
* **DAX**

---

## 📂 Project Workflow

### 1. Data Cleaning & Preparation

* Cleaned raw product dataset using Python
* Handled missing values and inconsistencies
* Created calculated fields such as discount percentage

### 2. SQL Analysis

* Imported cleaned dataset into SQL
* Performed exploratory data analysis using SQL queries
* Analyzed product counts, brand distribution, and pricing patterns

### 3. Data Transformation

* Used Power Query for data transformation
* Created Price Category groups:

  * Budget
  * Mid Range
  * Premium

### 4. Dashboard Development

Built an interactive Power BI dashboard containing:

* KPI Cards

  * Total Products
  * Total Brands
  * Average Product Price
  * Average Discount

* Visualizations

  * Top 10 Brands by Number of Products
  * Product Distribution by Price Category
  * Average Price by Price Category
  * Top 10 Brands by Average Retail Price

---

## 📈 Key Insights

* Average product discount is approximately **39%**
* Mid-range products represent the largest share of listings
* Significant variation exists in average pricing across brands
* Product listings are distributed across thousands of brands
